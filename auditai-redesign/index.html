行高规范说明
紧凑行高 1.2-1.3：用于大标题（Display / H1 / H2），减少标题占用空间，增强视觉冲击力。
标准行高 1.4-1.5：用于小标题与正文单行文本（H3 / H4 / 按钮），保证清晰可读。
舒适行高 1.6-1.7：用于多行正文（Body），提升长文本阅读舒适度，减少阅读疲劳。

动效规范

动效服务于交互反馈，时长适中、缓动自然，既保证操作响应感，又不影响审计工作效率。

缓动函数 · Easing

ease-out
cubic-bezier(0.16, 1, 0.3, 1)
退出动画、快速进入的元素，如按钮悬停、卡片上浮，给人轻快灵动的感觉。
ease-in-out
cubic-bezier(0.65, 0, 0.35, 1)
对称动画、循环动画，如进度条、状态切换，视觉平滑舒适。
ease-in
cubic-bezier(0.32, 0, 0.67, 0)
进入动画、需要加速离开的元素，如关闭弹窗、淡出隐藏。
